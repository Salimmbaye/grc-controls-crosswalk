# Security Controls Crosswalk — NIST CSF / 800-53 / ISO 27001 / CIS

A multi-framework security controls crosswalk delivered as an **Excel workbook** with a
built-in lookup tool, plus a **Word explainer**.

> Portfolio / lab project.

## What's here
- **`Controls-Crosswalk.xlsx`**:
  - **Crosswalk** — 31 control areas mapped across NIST CSF 2.0, NIST 800-53, ISO/IEC
    27001:2022, and CIS Controls v8, with AutoFilter.
  - **Lookup Tool** — pick a control area from a dropdown and its equivalent control in
    every framework fills in automatically (INDEX/MATCH formulas).
- **`Controls-Crosswalk-Report.docx`** — the "assess once, comply many" explainer, how the
  four frameworks differ, and the caveat that mappings are many-to-many judgments.

## Skills demonstrated
Framework fluency (NIST CSF, 800-53, ISO 27001, CIS) · control mapping · Excel lookup
functions (INDEX/MATCH), data validation & filtering.
